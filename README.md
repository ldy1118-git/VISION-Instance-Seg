# VISION Instance Segmentation — 생성형 AI 증강 실험

소규모 산업 결함 데이터에서 **전통 증강과 생성형 AI 증강이 각각 어떻게 작동하는지**, 함께 쓰면 어떤 변화가 일어나는지를 비교한 실험 코드입니다.

논문 「소규모 산업 결함 검출을 위한 생성형 AI 증강 효과」 (**KCC 2026**, 한국정보과학회) 의 실험 저장소입니다.

> 원본 저장소 [`Wlsghdh/VISION-Instance-Seg`](https://github.com/Wlsghdh/VISION-Instance-Seg) 의 개인 백업본입니다.

---

## 문제

산업 결함 검출은 구조적으로 **학습할 결함 이미지가 부족합니다.** 생산 현장에서 불량 발생 빈도 자체가 낮고, 결함 경계를 픽셀 단위로 표시하는 라벨링은 비용이 큽니다. 업계 표준 벤치마크인 VISION-Datasets가 클래스당 수십 장을 기준으로 삼는 것이 그 현실을 보여줍니다.

데이터를 늘리는 방법은 두 갈래입니다.

- **전통 증강** — 회전·반전·색상 변환. 계산 비용이 거의 없지만 결국 원본의 변형에 머뭅니다.
- **생성형 AI 증강** — 원본에 없던 결함 형태와 배경 조합을 만들어냅니다. 대신 생성 결과를 사람이 검수·라벨링해야 합니다.

소규모 조건에서 이 둘을 **동일 조건으로 비교하고, 결합했을 때를 분석한** 연구는 부족했습니다.

## 설계

VISION-Datasets 14개 카테고리 중 픽셀 라벨이 있고 경계가 뚜렷한 **3종**을 선정했습니다 — 주조 개재물, 콘솔 오염, 목재 이물질.

- 학습: **클래스당 원본 20장** (총 60장)
- 검증: 82장 (모든 조건 공통)
- 생성형 증강: 원본에서 결함을 제거해 배경을 만들고, 다른 이미지의 결함 형태를 참고해 새 위치·모양으로 합성 → **사람이 라벨링 후 재검수** (Gemini 2.0 사용)

네 조건을 비교했습니다: `원본` / `전통 증강 125장` / `생성형 AI 증강 125장` / `결합`

## 결과

### 같은 분량인데 효과가 정반대

전통 증강은 원본보다 성능을 **떨어뜨렸고**, 생성형 AI 증강은 **향상**시켰습니다. 세 클래스 모두 동일한 경향이었습니다.

소규모 조건에서는 증강 데이터의 **양보다 출처**가 중요합니다. 원본 20장이 담은 시각 패턴은 한정적이라, 픽셀 수준 변형만으로는 모델이 새로 배울 정보가 없고 오히려 과적합으로 이어집니다.

### 결합하면 더 오르지만, 임계점이 있다

원본 20장 + 생성형 125장을 기준(145장)으로 두고 전통 증강을 1~10배까지 늘려가며 측정했습니다. **8배 지점에서 최대**를 찍고 이후 감소했습니다. Cascade Mask R-CNN 기준 원본 대비 **약 +5 mAP**.

두 방식은 경쟁이 아니라 **보완** 관계입니다. 생성형 AI가 결함의 *의미 수준* 다양성을 넓히면, 전통 증강이 그 위에 *픽셀 수준* 변형을 더해 학습 신호를 두텁게 합니다. 다만 전통 증강이 과해지면 모델이 원본 분포로 다시 끌려갑니다.

### 모델 계열과 무관하게 재현

특정 구조만의 현상인지 확인하기 위해 **3개 계열 × 2개 = 6개 모델**에 동일 조건(전통 8배)을 적용했습니다.

| 계열 | 모델 |
|---|---|
| 2단계 CNN | Mask R-CNN, Cascade Mask R-CNN |
| 1단계 CNN | SOLOv2, RTMDet-Ins |
| 트랜스포머 | MaskDINO, Mask2Former |

**6개 모델 전부에서 결합 조건이 원본을 상회**했습니다. 트랜스포머 계열은 절대 성능이 낮은 구간에 머물렀는데, 클래스당 20장 수준에서 충분히 수렴하지 못한 것으로 해석됩니다.

## 한계

단일 seed 기준 보고이며, 결함 클래스가 3종으로 제한됩니다. 생성형 증강은 효과적이지만 **생성 이미지 검수와 라벨링에 수작업 비용**이 따른다는 점은 실제 도입 시 고려해야 합니다.

## 환경

`PyTorch` · `Detectron2` (ResNet-50 백본, COCO 사전학습) · `mmdetection` · `Albumentations`
학습률은 데이터량 변화와 무관하게 학습 강도가 유지되도록 반복 횟수 기반 cosine annealing 적용. 평가 지표는 mAP.
